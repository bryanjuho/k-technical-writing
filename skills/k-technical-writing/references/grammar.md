# 맞춤법, 띄어쓰기, 문장 부호

한국어 산문과 주석의 맞춤법, 띄어쓰기, 조사, 문장 부호를 확인합니다.

- 범위: 새로 쓰거나 이번에 고치는 줄

## 사용 방법

- 우선순위는 학습 규칙 > style.md > 이 문서입니다.
- 항목 제목의 심각도(`오류`, `개선`, `참고`)는 [../SKILL.md](../SKILL.md)의 검토 모드에 정의되어 있습니다. `오류` 항목은 새로 쓰거나 고치는 줄에서 바로 고칩니다.

검사하지 않는 대상은 다음과 같습니다.

- 코드 블록, 백틱 안 텍스트, 경로, 명령, 설정 키, 리소스 이름, 호스트 이름, URL
- 인용한 오류 메시지와 로그
- 한국어로 된 외부 식별자(그룹 이름, 메뉴 이름 등)
- 커밋 트레일러, 자동 생성 파일

## 맞춤법

### GR-01. 되/돼 (오류)

`되어`를 줄이면 `돼`입니다. `하`를 넣어 자연스러우면 `되`, `해`를 넣어 자연스러우면 `돼`입니다.

| 틀림 | 맞음 |
|---|---|
| 적용됬습니다 | 적용됐습니다 |
| 재시작되서 | 재시작돼서 |
| 동기화가 안되면 | 동기화가 안 되면 |

### GR-02. 안/않 (오류)

`안`은 부사, `않`은 `-지 않다`의 일부입니다. 예: Pod가 시작되지 않습니다. Pod가 안 뜹니다.

### GR-03. -로서/-로써 (오류)

`-로서`는 자격, `-로써`는 수단입니다. 수단을 말할 때는 `-로써`보다 `-로`가 자연스럽습니다(TE-15).

### GR-04. 자주 헷갈리는 짝 (오류)

- `-던`(과거 회상)과 `-든`(선택): 어느 노드든, 실행 중이던 Job
- `-ㄴ지`(형용사)와 `-는지`(동사): 값이 큰지, 동기화가 진행되는지
- `웬`과 `왠`: `왠`은 `왠지`에만 씁니다.

### GR-05. 외래어 표기 (개선)

[terminology.md](terminology.md)를 따릅니다. 제품 이름, 리소스 종류, 설정 키는 원문 표기 그대로 둡니다.

## 띄어쓰기

### GR-06. 의존 명사 (오류)

`것`, `수`, `만큼`, `뿐`, `줄`, `데`, `지`, `만`(시간)은 앞말과 띄웁니다.

| 틀림 | 맞음 |
|---|---|
| 적용할수있습니다 | 적용할 수 있습니다 |
| 확인한것 | 확인한 것 |
| 배포한지 3일 | 배포한 지 3일 |
| 3일만에 복구 | 3일 만에 복구 |

`데`는 뜻을 보고 정합니다. 장소나 일을 뜻하면 띄우고(`복구하는 데 30분이 걸렸습니다.`), 연결 어미 `-는데`는 붙입니다(`복구했는데 다시 멈췄습니다.`).

### GR-07. 보조 용언 (보고하지 않음)

`해 주다`와 `해주다`, `해 보다`와 `해보다`는 모두 맞습니다. 한 문서 안에서만 맞추고 지적하지 않습니다.

### GR-08. 숫자와 단위 (개선)

한글 맞춤법 제43항은 아라비아 숫자 뒤 단위를 붙여 쓰는 것을 허용합니다. 이 스킬은 붙여 씁니다(ST-15).

- 한국어 단위를 붙여 씁니다. 예: `30분`, `7일`, `3개`, `2회`
- 영문 단위도 붙여 씁니다. 예: `256MB`, `20GB`, `100ms`
- 설정 값은 원문 그대로 백틱으로 감쌉니다. 예: `` `12Gi` ``, `` `500m` ``. `12 GiB`처럼 바꿔 쓰지 않습니다.
- 본문의 큰 수에는 천 단위 쉼표를 씁니다(`2,048개`). 코드 값과 설정 값에는 넣지 않습니다.

### GR-09. 합성어 (개선)

굳은 합성어는 붙이고, 그 밖의 용어는 [terminology.md](terminology.md)의 표기를 따릅니다. 예: 재시작, 기본값, 환경 변수, 자격 증명

### GR-10. 조사 띄어쓰기 (오류)

조사는 앞말에 붙입니다. 영어 단어, 백틱 코드, 숫자 뒤에서도 붙입니다(ST-08).

| 틀림 | 맞음 |
|---|---|
| 노드 에서 | 노드에서 |
| API 를 | API를 |
| `` `config.yaml` 을 `` | `` `config.yaml`을 `` |

## 조사 고르기

### GR-11. 받침에 맞는 조사 (오류)

영어, 코드, 숫자 뒤에서는 읽는 소리의 받침으로 고릅니다. `ㄹ` 받침 뒤 `로`/`으로`는 `로`입니다.

| 토큰(읽는 소리) | 받침 | 조사 |
|---|---|---|
| `Secret`(시크릿), `ConfigMap`(컨피그맵), `CronJob`(크론잡) | 있음 | 을, 은, 이, 과, 으로 |
| `Ingress`(인그레스), `Pod`(파드), `API`(에이피아이) | 없음 | 를, 는, 가, 와, 로 |
| `Helm`(헬름), `production`(프로덕션) | 있음 | 을, 은, 이, 으로 |
| `URL`(유알엘), `` `1` ``(일) | ㄹ | 을, 은, 이, 로 |
| `` `3600` ``(삼천육백) | 있음 | 을, 으로 |

읽는 소리가 갈리는 토큰(`kubectl`, `2Gi`)은 `` `kubectl` 명령으로``, `` `2Gi` 값을``처럼 명사를 하나 넣고 조사를 붙입니다.

## 문장 부호

### GR-12. 가운뎃점 (참고)

기본값은 가운뎃점을 쓰지 않는 것입니다(D-02). 셋 이상은 쉼표로 나열하고, 명사구 안의 짝 명사는 `및`으로 잇습니다.

- 전: 생성·수정·삭제 권한을 Deployment·Service·Ingress에 부여합니다.
- 후: Deployment, Service, Ingress에 생성, 수정, 삭제 권한을 부여합니다.

### GR-13. 값 변화 화살표 (개선)

변경이력 항목과 표에서는 이전 값과 이후 값을 `→`로 잇고 값을 백틱으로 감쌉니다. `->`는 쓰지 않습니다(ST-13).

### GR-14. 범위와 근사 (개선)

- 범위는 물결표를 붙여 씁니다. 예: `10~20초`, `09:00~18:00(KST)`
- 근사는 물결표 대신 `약`을 씁니다. 예: `최대 ~180초` → `최대 약 180초`
- en dash(`–`) 범위는 물결표로 바꿉니다.

### GR-15. 괄호 앞 띄어쓰기 (오류)

여는 괄호는 앞말에 붙입니다. 예: `가용 영역(availability zone)`, `보존 기간(일)`

### GR-16. 마침표 (개선)

완결된 문장은 마침표로 끝냅니다. 제목, 커밋 제목, 표 칸, 명사형 목록 항목, 한 줄 주석, 알림 `summary`에는 찍지 않습니다(ST-02, ST-03).

### GR-17. 쉼표 (개선)

한국어는 영어보다 쉼표를 적게 씁니다. 주어 뒤, 조건절 뒤, 연결 어미 뒤 쉼표는 대부분 뺍니다. 자세한 기준은 [ai-patterns.md](ai-patterns.md)의 AP-14~AP-16에 있습니다.

### GR-18. 따옴표, 백틱, 느낌표 (개선)

- 입력하거나 검색할 리터럴(경로, 키, 플래그, 리소스 이름)은 백틱으로 감쌉니다.
- 화면 문구와 다른 사람의 말은 큰따옴표로 감쌉니다.
- 느낌표는 쓰지 않습니다.

## 문장 구조

### GR-19. 주어와 서술어 호응 (개선)

긴 수식어 뒤에서 주어와 서술어가 어긋나지 않는지 확인합니다.

- 전: 이 설정의 목적은 노드가 재시작되어도 볼륨이 다시 마운트됩니다.
- 후: 이 설정의 목적은 노드가 재시작되어도 볼륨을 다시 마운트하는 것입니다.

### GR-20. 어미 통일 (오류)

문장은 합니다체 하나로 씁니다(ST-01). 해라체나 해요체가 섞이면 고칩니다.

- 전: 설정 파일을 수정한다. 그다음 서비스를 재시작해요.
- 후: 설정 파일을 수정합니다. 그다음 서비스를 재시작합니다.

### GR-21. 이중 부정 (참고)

뜻을 일부러 살리는 경우가 아니면 긍정문으로 씁니다. 예: `복구가 불가능하지 않습니다` → `복구할 수 있습니다`
