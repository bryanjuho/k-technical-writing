# 점검 목록

- 새로 쓰거나 고치는 줄만 점검
- 코드 블록, 백틱 안 텍스트, 식별자, 인용한 오류 메시지는 제외
- 의미(행위자, 가능과 필연, 조건, 범위)가 바뀌면 고치지 않음
- 자연스러운 문장은 그대로 유지

## 맞춤법, 띄어쓰기 (오류)

| 항목 | 틀림 | 맞음 |
|---|---|---|
| 되/돼 | 적용됬습니다, 재시작되서 | 적용됐습니다, 재시작돼서 |
| 안/않 | 동기화가 안되면, 시작되지 안습니다 | 동기화가 안 되면, 시작되지 않습니다 |
| -던/-든 | 어느 노드던 | 어느 노드든 |
| 의존 명사 | 적용할수있습니다, 배포한지 3일, 한개 | 적용할 수 있습니다, 배포한 지 3일, 한 개 |
| -는 데/-는데 | 복구하는데 30분이 걸렸습니다. | 복구하는 데 30분이 걸렸습니다. |
| 조사 띄어쓰기 | 노드 에서, API 를 | 노드에서, API를 |
| 받침과 조사 | `Ingress`을, `Secret`를, `URL`으로 | `Ingress`를, `Secret`을, `URL`로 |
| 주어와 서술어 | 이 설정의 목적은 볼륨이 다시 마운트됩니다. | 이 설정의 목적은 볼륨을 다시 마운트하는 것입니다. |

- 읽는 소리가 갈리는 토큰은 명사를 넣고 조사 연결. 예: `` `kubectl` 명령으로 ``
- `해 주다`/`해주다`, `해 보다`/`해보다`는 둘 다 맞음. 문서 안에서만 통일

## 번역투 (개선)

| 패턴 | 전 | 후 |
|---|---|---|
| `~에 대해` | 백업 정책에 대해 검토했습니다. | 백업 정책을 검토했습니다. |
| `~를 통해` | 환경 변수를 통해 주입이 이루어집니다. | 환경 변수로 주입합니다. |
| `~에 있어서` | 마이그레이션에 있어서 권한이 문제가 됩니다. | 마이그레이션할 때 권한이 문제가 됩니다. |
| `~와 관련된` | 보안과 관련된 설정 | 보안 설정 |
| `~에 기반하여` | 측정 결과에 기반하여 결정했습니다. | 측정 결과를 보고 정했습니다. |
| `가지고 있습니다` | 노드는 고유한 레이블을 가지고 있습니다. | 노드마다 고유한 레이블이 있습니다. |
| `~되어지다` | 매일 생성되어집니다. | 매일 생성됩니다. |
| `~에 의해` | Argo CD에 의해 동기화됩니다. | Argo CD가 동기화합니다. |
| `~할 수 있습니다` 남용 | 이 명령으로 서버를 시작할 수 있습니다. | 이 명령으로 서버를 시작합니다. |
| `~을 위해` | 원인 파악을 위해 로그를 수집합니다. | 원인을 찾으려고 로그를 수집합니다. |
| `~라는 점에서` | 평문이라는 점에서 커밋할 수 없습니다. | 평문이므로 커밋할 수 없습니다. |
| `~것입니다` | 로그가 쌓이지 않을 것입니다. | 로그가 쌓이지 않습니다. |
| `~로 인해 발생` | 토큰 만료로 인해 인증 오류가 발생합니다. | 토큰이 만료되면 인증에 실패합니다. |
| `~함으로써` | `1`로 설정함으로써 막습니다. | `1`로 설정해 막습니다. |

- 실제 가능성이나 위험을 말하는 `~할 수 있습니다`는 유지
- 실제 네트워크 경로의 `~를 통해`는 유지. 예: VPN을 통해 접근

## AI 문체 (개선)

| 패턴 | 전 | 후 |
|---|---|---|
| 만능 한자어 동사 | 교체 작업을 진행한 후 동기화를 실시합니다. | 교체한 뒤 동기화합니다. |
| 추상 주어 | 이번 변경은 안정성 향상을 가져옵니다. | 재시도 횟수를 2회로 줄였습니다. |
| `-들` 남용 | 여러 노드들의 볼륨들 | 여러 노드의 볼륨 |
| `이것은`, `해당` 반복 | 해당 볼륨을 삭제하고 해당 Pod를 재시작합니다. | 볼륨을 삭제하고 Pod를 재시작합니다. |
| 맺음 관용구 | 결국 캐시가 원인이었던 셈입니다. | 원인은 캐시였습니다. |
| `~적 N` | 구조적 한계를 고려한 선택입니다. | 볼륨을 두 노드에 연결할 수 없어 복제본을 1개로 유지합니다. |
| `의` 연쇄 | 보존 기간의 단축의 적용 | 보존 기간 단축 |
| 접속 부사 남용 | 또한 …. 따라서 …. | 연결 어미로 연결하거나 삭제 |
| 쉼표 남용 | Argo CD는, 변경을 감지하면, 적용합니다. | Argo CD는 변경을 감지하면 적용합니다. |
| 쉼표로 이은 긴 문장 | A이고, B이며, C입니다. | 사실마다 문장 분리 |
| 문장 끝 콜론 | 다음과 같습니다: | 콜론 없이 마침표 |
| 굵게 남용 | 문단마다 여러 곳 굵게 | 화면 요소, 참고와 주의 라벨에만 |
