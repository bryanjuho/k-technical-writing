# 용어

용어 표기 원칙과 자주 쓰는 용어 목록입니다. 프로젝트마다 다른 용어는 프로젝트 학습 규칙(`.k-technical-writing/learned-rules.md`)에 둡니다.

## 표기 원칙

1. 제품, 서비스, 기능, API 작업 이름은 공식 표기 그대로 씁니다. 예: `Kubernetes Engine`, `Secrets Manager`, `GitHub Actions`
2. Kubernetes 리소스 종류는 영어로 쓰되 백틱 없이 씁니다. 설정 키는 백틱으로 감쌉니다. 예: Deployment를 생성합니다. `spec.replicas`를 `2`로 설정합니다.
3. 일반 개념은 국립국어원 외래어 표기법에 따른 표기나 한국어 용어를 씁니다. 예: 클러스터, 네임스페이스, 메시지, 콘텐츠
4. 처음 나오는 용어는 `한국어(English)`로 한 번 쓰고 이후에는 한국어만 씁니다.
5. 약어는 처음에 `풀이(약어)` 또는 `약어(풀이)`로 쓰고 이후에는 약어만 씁니다. 예: 역할 기반 접근 제어(RBAC)
6. 한 문서 안에서는 한 용어를 한 표기로 씁니다.

## 동사

| 쓰는 표현 | 쓰지 않는 표현 | 예 |
|---|---|---|
| 생성합니다, 만듭니다 | 둡니다(생성의 뜻으로) | 백업 버킷을 생성합니다. |
| 설정합니다 | 지정합니다, 둡니다(값을 정하는 뜻으로) | 보존 기간을 7일로 설정합니다. 대상을 고르는 뜻(`노드를 지정합니다`)이면 `지정합니다`도 씁니다. |
| 추가합니다 | 더합니다 | 환경 변수를 추가합니다. |
| 노출합니다, 공개합니다 | 냅니다 | 서비스를 `443` 포트로 노출합니다. |
| 사용합니다 | 씁니다(도구, 명령, 기능을 쓰는 뜻일 때) | `pg_dump`를 사용합니다. 표기나 표현을 고르는 뜻의 `씁니다`는 괜찮습니다. |
| 접근할 수 있습니다, 연결됩니다 | 닿습니다 | 내부 네트워크에서만 접근할 수 있습니다. |
| 기록합니다, 보관합니다 | 남깁니다(로그와 기록의 뜻으로) | 실행 결과를 로그에 기록합니다. |
| 적용합니다 | 반영시킵니다 | 변경 사항을 클러스터에 적용합니다. |
| 확인합니다 | 체크합니다 | 상태를 확인합니다. |
