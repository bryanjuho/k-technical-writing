# 용어

- 제품, 서비스, 기능 이름은 공식 표기. 예: GitHub Actions, Secrets Manager
- Kubernetes 리소스 종류는 원문, 백틱 없음. 설정 키는 백틱. 예: Deployment를 생성합니다. `spec.replicas`를 `2`로 설정합니다.
- 일반 개념은 한국어 또는 외래어 표기법 기준 표기
- 처음 나오는 용어는 `한국어(English)` 병기, 이후 한국어만
- 약어는 처음에 `풀이(약어)` 병기. 예: 역할 기반 접근 제어(RBAC)
- 프로젝트별 용어는 프로젝트 학습 규칙에 기록

## 동사

| 사용 | 사용 안 함 | 예 |
|---|---|---|
| 생성합니다 | 둡니다, 만들어 둡니다 | 백업 버킷을 생성합니다. |
| 설정합니다 | 지정합니다, 둡니다(값을 정하는 뜻) | 보존 기간을 7일로 설정합니다. |
| 지정합니다 | | 대상을 고르는 뜻. 예: 노드를 지정합니다. |
| 추가합니다 | 더합니다 | 환경 변수를 추가합니다. |
| 노출합니다 | 냅니다 | 서비스를 `443` 포트로 노출합니다. |
| 사용합니다 | 씁니다(도구, 명령, 기능) | `pg_dump`를 사용합니다. |
| 접근할 수 있습니다 | 닿습니다 | 내부 네트워크에서만 접근할 수 있습니다. |
| 기록합니다 | 남깁니다 | 실행 결과를 로그에 기록합니다. |
| 적용합니다 | 반영시킵니다 | 변경 사항을 클러스터에 적용합니다. |
| 확인합니다 | 체크합니다 | 상태를 확인합니다. |
