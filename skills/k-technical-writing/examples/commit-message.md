# 커밋 메시지

## 전

```text
설정(production): ingress 에 타임아웃·버퍼링 설정을 둔다 — 업로드가 60초에 끊기던 문제 (#123)

대용량 업로드가 60초에서 끊겼다. proxy-read-timeout 을 600 으로 늘리고 버퍼링을 끈다.
```

## 후

```text
fix(ingress): 대용량 업로드가 60초에 끊기던 문제 수정 (#123)

대용량 파일을 업로드하면 60초 후 연결이 끊겼습니다.
`proxy-read-timeout`을 `60` → `600`으로 늘리고 요청 버퍼링을 끕니다.

production 환경에만 적용합니다.
```

## 바꾼 점

- 제목은 `type(scope): 명사형 요약` 형식으로 썼습니다(D-06).
- 제목에 한 가지 변경만 썼습니다. 설정 값은 본문으로 옮겼습니다.
- 본문은 합니다체로 썼습니다(ST-01).
- 값 변화는 화살표로, 설정 키는 백틱으로 썼습니다(ST-10, ST-13).
- 제목 끝 PR 번호는 관례에 따라 한 칸 띄웠습니다(ST-15).
