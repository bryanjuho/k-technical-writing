# API 레퍼런스

## 전

```markdown
| 필드 | 설명 |
|---|---|
| `retentionDays` | 백업을 보관하는 일수를 지정할 수 있는 필드이다. 1 에서 365 까지 가능하며, 안 넣으면 7 이 들어간다 |
| `encrypted` | 암호화를 할지 말지 |
```

## 후

```markdown
| 필드 | 설명 |
|---|---|
| `retentionDays` | 백업 보존 기간(일)<br>- 1~365 입력<br>- 미입력 시 기본값 `7` |
| `encrypted` | 암호화 사용 여부 |
```

## 바꾼 점

- 필드 설명은 명사구로 시작했습니다(ST-23).
- 제약과 기본값은 명사형 줄로 나눠 썼습니다(D-12). 줄을 나누기 어려운 자리에서는 `백업 보존 기간(일). 1~365 사이 값이어야 합니다. 기본값은 `7`입니다.`처럼 문장으로 씁니다.
- 불리언 필드는 `~ 여부`로 썼습니다.
- 범위는 물결표로, 기본값은 백틱으로 썼습니다(GR-14, ST-10).
