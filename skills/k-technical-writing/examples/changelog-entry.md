# 변경 기록 항목

서술형 문단으로 쓴 변경 기록을 명사형 항목으로 바꾼 예입니다.

## 전

```markdown
## [Unreleased]

### Fixed
- **노드 재시작 후 백업 볼륨이 마운트되지 않던 문제.** 노드가 재시작되면 `/backup` 이 비어 있었고
  백업 Job 이 `No such file or directory` 로 멈췄다. `/etc/fstab` 에 `nofail` 을 둔다 — 재시작 뒤에도
  마운트가 돌아오고, 디스크가 없을 때도 부팅이 막히지 않는다. 보존 기간도 `7d` 에서 `14d` 로 늘린다.
```

## 후

```markdown
## 2026. 11. 9.

### 수정

- 노드 재시작 시 백업 볼륨이 마운트되지 않던 문제 수정

### 변경

- 백업 보존 기간 `7d` → `14d` 변경
```

## 바꾼 점

- 날짜 제목과 한국어 분류를 썼습니다(ST-22, D-03).
- 항목 하나에 변경 하나만 썼습니다. 보존 기간 변경은 `변경` 분류로 옮겼습니다.
- 버그 수정은 `~ 시 ~하던 문제 수정` 형식으로 썼습니다.
- 원인과 조치 방법(`nofail` 옵션)은 변경 기록에서 빼고 PR 본문이나 커밋 본문에 씁니다.
- 줄표와 띄어 쓴 조사를 없앴습니다(ST-08, ST-14).
