# k-technical-writing

An agent skill that writes docs in the style of Korean technical docs and commercial software changelogs.

[한국어](README.md)

## Install

```bash
# Claude Code
claude plugin marketplace add bryanjuho/k-technical-writing
claude plugin install k-technical-writing@k-technical-writing

# Codex
codex plugin marketplace add bryanjuho/k-technical-writing
codex plugin add k-technical-writing@k-technical-writing

# pi
pi install git:github.com/bryanjuho/k-technical-writing

# Other agents
npx skills add bryanjuho/k-technical-writing
```

Rules: [style.md](skills/k-technical-writing/references/style.md)
